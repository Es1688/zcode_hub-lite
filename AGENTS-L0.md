# Global Engineering Rules — Level 0 (Lite)

> Устанавливается как `<ZCODE_DIR>/AGENTS.md`. Плейсхолдер `<ZCODE_DIR>` заменяется
> установщиком install_lite.py на фактический каталог конфигурации ZCode.

## Язык
- Общение и документация — на русском; код, идентификаторы, commit-сообщения — на английском.

## Обучение
- Пользователь учится разработке и git: каждую выполняемую команду сопровождай
  коротким пояснением «что она делает и зачем», простым языком.
- Не выполняй молча действия, смысл которых пользователю ещё не знаком, — сначала
  короткое пояснение.

## Безопасность
- Никогда не выводи и не коммить секреты (API-ключи, токены, пароли, *.key, .env).
  Перед `git add` проверь .gitignore.
- Опасные операции (удаление файлов, rm -rf, сброс истории git, изменение конфигурации
  ZCode и системных настроек) — только после явного подтверждения пользователя.
- Файловая система: агент работает внутри рабочего корня, заданного в конфигурации
  стража guard (`strict_fs_root`). Доступ вне него блокируется стражем — не пытайся
  обойти, запроси разрешение у пользователя.
- Эталонные данные (каталоги DATASTOR, REPORTS, legacy) — только чтение, не изменять.
- Конфиги и логи с ключами в каталоге ZCode не читать и не копировать без прямой задачи.

## Git
- git push, merge в main, удаление веток с потерей истории — только с явного разрешения
  пользователя.
- Коммит-сообщения: Conventional Commits (feat/fix/docs/refactor/test/chore), английский.
- Перед коммитом прогони тесты/линтер, если они есть; правила проекта — в .zcode/project.yaml.

## Проекты
- В каждом репозитории сначала прочитай AGENTS.md проекта (Level 1) и
  .zcode/project.yaml — их правила перекрывают эти.
- Задачи ведутся в `.zcode/tasks/<id>.md`: начало — скилл git-start-task, закрытие —
  git-finish-task.

## Стиль работы
- Минимальные изменения в стиле существующего кода; комментарии — только для неочевидных
  ограничений.
- Закончи начатое: проверь результат; о пропущенных шагах и ошибках докладывай честно.
